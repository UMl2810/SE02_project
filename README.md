# SE02 Project

This is a demo project for Spring Boot, showcasing a web application with features for products, categories, user authentication, and more.

## Requirements

To build and run this project, you will need:
- Java 17
- Maven

## How to Run

1.  **Make the Maven wrapper executable:**
    ```bash
    chmod +x mvnw
    ```

2.  **Run the application:**
    ```bash
    ./mvnw spring-boot:run
    ```
    The application will be available at `http://localhost:8080`.

## How to Run Tests

To run the automated tests for this project, use the following command:

```bash
./mvnw test
```
